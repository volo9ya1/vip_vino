# 🍷 VIP VINO — Итальянские традиции с 2006 года

Современный и стильный веб-сайт премиальной коллекции натуральных вин, игристых напитков и шампанского. Проект выполнен в элегантном дизайне с использованием эффекта **Liquid Glass** (матовое полупрозрачное стекло).

## 🚀 Особенности проекта
* **Интерактивный каталог и прайс-лист:** Удобная фильтрация по категориям (вина, игристые напитки).
* **Корзина покупок:** Возможность добавлять товары и рассчитывать общую стоимость заказа.
* **Skeleton-загрузка:** Плавная анимация загрузки контента для улучшения пользовательского опыта.
* **Адаптивность:** Полная оптимизация под мобильные телефоны, планшеты и ПК.
* **Мультиязычность описаний:** Информация о напитках представлена на русском и узбекском языках.

## 🛠️ Используемые технологии
* **HTML5** — структурированная разметка страниц (`index.html`, `catalog.html`, `contacts.html`).
* **CSS3** — кастомные стили, анимации и современный дизайн с поддержкой `backdrop-filter`.
* **JavaScript (ES6+)** — динамическое управление каталогом, фильтрами и логикой корзины.
